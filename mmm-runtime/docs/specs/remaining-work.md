## 口径分歧，已登记在各自 Skill 里

平台自己的文档与代码就不一致，runtime 跟随代码，但对客户说哪一套需要统一：

- **统计检验总分**：文档与真实工作簿是"三项相加、四档、≥3 良好"，代码是"三项相乘、三档、>0.5 良好"。
  runtime 跟随代码。乘法更严：信号强但共线的指标会被一票否决。
- **异常判据**：设计文档、平台代码、runtime 三套都不一样。已作为必答澄清点。
- **质量三态**：平台代码 0.5 即自动通过，设计文档写 0.5 交人决策。
  runtime 取："==1 自动通过 / 0<总分<1 交人 / ==0 弃用"。
