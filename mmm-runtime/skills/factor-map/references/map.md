# factor-map/map —— 把因子树与已发布数据配对（C）

## 五个动作

工具一次跑完，你负责读结果、检查它是不是可信、把该问的整理成选择题。
工具卡见 `tools/catalog/data.factor-map.yaml`。

| # | 动作 | 说明 |
|---|---|---|
| 1 | 取活跃因子行 | 只取已确认的行。还没被采纳的建议行不进映射表——一个还没被采纳的因子谈不上有没有数据 |
| 2 | 建双向桥 | 每一行把**三种叫法**都登记到它的 L4 下：行自己的指标名、它已有供给记录用的指标名、行上的指标字段；再把数据侧的叫法登记进来。冲突时先登记者胜，但"已绑定"压过"已声明" |
| 3 | 判三态 | `mapped` / `ignored` / `pending`，判定顺序见下 |
| 4 | 找无人认领的指标 | 已发布、但没有供给任何活跃行的指标。**响应指标永远不算** |
| 5 | 给待定行打候选 | 在无人认领的指标里打分排序，取 ≥ 0.30 的前 5 个 |

## 三态怎么判（确定性，你不参与）

```
默认                          pending
如果这一行在排除集里      →   ignored     ← 优先级最高
否则如果有供给它的记录    →   mapped
```

**"明确排除压过自动映射"是一条载重规则，不是风格选择。** 理由见 SKILL.md。

**无论判成什么，供给信息都要填上**（数据源名、指标名、覆盖区间）。
一个正在考虑要不要恢复某个被排除行的人，需要看见现在到底有什么数据。

同一行有多条供给记录时的主选：**人钉的胜出**，否则取行数最多的那一条（序列最长）。
**绑定操作同时清除排除**——一个被排除的行，一旦被绑上就不再是"主动不解决"了。

## 四级查找（由细到粗，越界即停）

1. 已显式指定的因子行（发布时匹配上的，或人钉的）—— 权威，直接用
2. 全路径 + 名称：`(l1,l2,l3,l4, 指标) == (l1,l2,l3,l4, 指标名)`
3. 仅路径：`(l1,l2,l3,l4)`
4. L3 + 名称：`(l3, 指标) == (l3, 指标名)`

第 2–4 级只在"该候选行还没被别的指标认领"时才生效。这把锁修掉的是真实事故：
路径查找曾把「温度」绑到声明「降水量」的行上、把「竞品ND」绑到声明「竞品WD」的行上。

## 候选分数怎么读

```
分数 = 0.45 × 名称 + 0.35 × 路径 + 0.12 × 单位 + 0.08 × 覆盖
```

| 分项 | 怎么算 |
|---|---|
| 名称 | 词元集合的重合度。词元按空格与常见分隔符切分，中日韩再加 2-gram（"冰柜台数" → `冰柜`,`柜台`,`台数`） |
| 路径 | 逐级相等，权重 L1=0.5 · L2=0.75 · L3=1.5 · L4=2.0，除以 4.75。**一级都不匹配就是 0** |
| 单位 | 候选的单位与这一行的指标名落进同一个词汇组则 1，否则 0。三组：金额 / 销量 / 比率 |
| 覆盖 | 候选同时有起止月份则 1 |

| 阈值 | 值 | 含义 |
|---|---|---|
| 呈现下限 | 0.30 | 低于此分**根本不呈现**。一个 0.2 分的建议消耗的注意力比它值的多 |
| 条数上限 | 5 | 排序后取前 5 |
| 措辞分档 | ≥0.6 "很可能匹配" · ≥0.45 "可能匹配" · 其余 "弱匹配" | **只影响措辞，不影响分数** |

**你能改的只有那一句解释，而且要 ≤20 个字、看起来不对就直说。**
分数与匹配本身永不经过你。这里不做自动绑定——有人在场的流程不需要它，
而且它会给所有剩余待定行批量打上"自动：没有匹配的指标"的排除，
那正是本交付物明令禁止的那种批量排除。

## 无人认领与"歧义"不是一回事

- **无人认领**：四级查找全部落空，且它不是响应指标。列出来，指向因子树。
- **歧义**：参考树上有 50 行都声明了「花费」；一个叫「花费」的指标在 L4 上对不上时，
  它是歧义。按无人认领去采纳会凭空造出一个和已有因子重复的行。
  **单列成"名称歧义，需要指定 L4"。**

## 写产出物

照 `../templates/factor-map.yaml` 填。数字全部来自工具的运行结果，
**逐字誊抄，不四舍五入、不重算**：每一行的候选分数、覆盖行数、区间，都有 `source`
指回它是从哪一条结果抄来的。

重算时，人写过的排除理由与"谁定的"要原样带回来。**它们是决定，不是可以被重新推导的东西。**

写完交给编排层验收：「因子映射已写好，请验收 factor-map/map」。
