# 项目日报

`status` 回答"现在什么样"。日报回答**"昨天到今天变了什么、谁欠谁、什么在冒烟"**——
一份只复述状态的日报，第二天就没人看了。

**这个 Skill 不产出交付物。** 它不开确认、不改进度记录、不写 `artifacts/`。
它读，它算，它讲。

**开始前：** 读 `../../shared/conventions.md` 定位工作区。

## 第 0 步 · 澄清（先跑完脚本再问）

先把脚本跑出来，八段都在眼前了再决定要不要问。多数情况一个都不用问。

| 澄清点 | 什么时候必须问 | 推荐 |
|---|---|---|
| 报哪个工作区 | 用户没说，且当前目录不是工作区 | 先 `state.py list` 再问，别新建 |
| 报哪一天 | 用户要补昨天的 | 用 `--date`，并说清这是补报 |
| 要不要全展开 | 某一段被折叠、而用户正好在问那一段 | 只对那一段用 `--full`，不整份重报 |

## 构建步骤

| # | 步骤 | 类型 | 做什么 | 详细 |
|---|---|---|---|---|
| 1 | `run` | M | 跑脚本，八段一次算齐，顺带留下今天的快照 | 下面「怎么跑」 |
| 2 | `read` | A | 按八段的顺序讲出来，该点名的点名 | `references/sections.md` |
| 3 | `flag` | C | 风险分两类讲，每条挂出处 | `references/risks.md` |

## 怎么跑

```bash
~/.local/bin/mmm script daily_report <工作区>
```

`--full` 全展开 · `--date YYYY-MM-DD` 补报某天 · `--json` 看原始结构 ·
`--no-snapshot` 试跑时不留快照。

正常跑一次就会把今天的快照写进 `state/daily/<日期>.json`——**明天的"变了什么"靠的就是它**，
所以除非在试，否则不要加 `--no-snapshot`。

## 硬规矩

**一个数都不许你写。** 八段里的每一个数字都来自这次脚本运行的输出，你只做转述。
算不出来的数就是没有这个数——`shared/numbers-provenance.md` 管着这条，
日报是给人做判断用的，编出来的进度比没有进度更坏。

**"等你决定"排第一段。** 日报是用来驱动人动的，不是陈列状态的。
没有等人的事，一句"没有卡在人这边的事"带过，把版面留给变化和风险。

**进度记录和磁盘对不上时，先讲这个。** 产出物在盘上、进度记录里却是未完成，
说明有人绕过验收干了活。这时候报"未开始"是唯一的错答案——先说分叉，
让编排层核对，再谈别的。

**变化为空是结论，照说。** "和昨天相比没有变化"要说出来。首日没有对照就说首日，
不要拿今天的绝对值冒充变化——那是把状态伪装成进展。

**两类风险不能混着报。** 业务性的在前（要打电话、要改交付说明），机制性的在后
（这套流程内部的账）。一条都没有时两边都明说。

**过期视图要点名。** 源文件改了、渲染的那份没重生成，它读起来和正确的一模一样，
发出去就是事故。脚本已经把重新生成的命令给你了，照抄。

**别复述整份输出。** 脚本已经折叠过一次了。八段里空的、正常的，一句带过；
把话留给变了的、卡住的、冒烟的。一份需要往下翻三屏的日报和没写一样。

**不要替用户做决定。** 日报只到"这件事在等你、它卡住了这些"为止。
真要拍板，那是编排层开确认的事，不在这儿。

## 取材范围

只读，不写——除了 `state/daily/<日期>.json` 这份自己的快照。

| 步骤 | 只能读 |
|---|---|
| run | 工作区全域（脚本自己按需取），插件的流程定义与检查定义 |
| read | 脚本这次的输出 |
| flag | 脚本这次的输出 |

第 2、3 步**只读脚本的输出**，不再回头翻原始文件。回头翻就会开始"顺手"算数，
而顺手算出来的数没有出处。

## 产出

没有交付物。终端上的一份摘要，外加 `state/daily/<日期>.json` ——
那是明天做差分的对照，机器记账，不是给人看的东西，也不需要谁验收。

## 说话的规矩

1. 先说结论，再说依据，不铺垫。开口第一句是今天最要紧的那件事，不是项目名。
2. 只说业务语言：说「确认」「检查项」「交付物」「计算结果」，不说 gate、predicate、artifact。
3. 每步三句话内交代：做了什么 / 结果是什么 / 需要你什么。
4. 要人拍板时永远给选择题：候选 + 推荐 + 每项后果。日报本身不开确认——
   要拍板就交给编排层，别在日报里就地问。
5. 数字要报出处。说不出出处的数字就不说。说"44 个因子从未拿到数据"，不要说"数据缺口较大"。
6. 拿不准就问。"大致""可能""建议进一步确认"通常是该问没问留下的痕迹。
