# 步骤 anomalies —— 定位异常、生成假设（M + C）

```bash
~/.local/bin/mmm tool validation.anomalies --workspace <工作区>
```

写出 `data/derived/anomalies.json`：每个 (渠道 × 年) 一张卡，带变动幅度和算它用了什么。
你照 `../templates/anomalies.yaml` 写 `artifacts/s2/anomalies.yaml`——补上假设、依据、代价
和提名处置，客户裁定之后把裁定也写回去。

## 判据：响应变量按渠道的年度同比，超过 ±40%

**只扫响应变量。** 认不出响应就一条都不报，并明说去数据处理那一步标 KPI 角色 ——
绝不退化成把整张表加起来。平台踩过这个坑：识别不到销量时它会把花费、温度、比率求和当成
Y，然后在那上面很有信心地报异常。

判据是一个**业务数字**而不是一个统计量，这是有意的：裁定这些卡的人是用百分比说话的，
一张"这一期的同比变动是常年的 6.8 倍中位绝对偏差"的卡，没有人能在会上复述。

最多 8 条，按幅度排序。**零个异常是一个答案，不是缺口。**

## 比得过才算数

两年的月份或构成对不上时，工具会先取交集再比，并把设为一旁的东西写进 `windowNote`。
你在呈现时要把这句话带上。

取的是 **(月份 × 切片) 的格子交集**，不是月份集合和切片集合各取一次。差别在这里：
一个去年只报了一个月、今年报了满年的区域，在两个集合里都在，两次独立取交集都留得下来，
然后给其中一年贡献十一个月、另一年贡献零个 —— 于是每个渠道都凭空多出几十个百分点，
而客户被派去找一个根本不存在的原因。

拿半年的今年比整年的去年，同理。

## 下钻是这一步的一半

工具在（渠道 × 年）上定位，**不下钻**。下钻是你的活，而且现在**在页面上做**：
打开那张卡，把渠道筛到出问题的那个，沿 L4–L8 往下钻，看是哪一层塌的。

结论形态："2025 年 · O2O × 美团闪购，销量同比 -51%，从 1 月起整段都低。"

数据里没有那一层就写"该因子只报到 L5，无法再往下"——空着不解释会读成"下钻过了，
没发现什么"。

## 假设卡

每个异常一张，三件事缺一不可：

| 字段 | 要求 |
|---|---|
| `hypothesis` | ≤25 词，只基于渠道、年份、幅度。**猜不出就写"未从数据中确立"，不得凭空造事件** |
| `rationale` | 为什么提议这个处置——你在数据里看到了什么支持它 |
| `tradeoff` | 这个处置的代价是什么 |

**证据为空是一个合法的答案，而且是个有用的答案**："记录里没有任何东西能解释这个窗口"
比编一个代理更换事件强得多。造出来的事件会被客户当成我们知道的事，然后在会上被拆穿。

访谈纪要与行业材料是唯二允许引的两类材料。

## 三种处置，各自真的做什么

| `status` | `handling` | 对拟合的效果 |
|---|---|---|
| `accepted` | `event` | 窗口内加一列 0/1 控制项——这次冲击被当成生意本身吸收，不算到媒体头上 |
| `accepted` | `cap` | 窗口内把响应缩尾 |
| `accepted` | `raw` | 数据不动，作为一句说明带进报告 |
| `rejected` | 任意 | 什么都不做——判定它根本不是异常 |
| `pending` | 任意 | **什么都不做。** 一个没人复核过的猜想不许悄悄改变模型 |

**`handling` 没有 `rejected` 这个取值。** 不认可这条异常，是把 `status` 写成 `rejected`，
不是把 `handling` 写成它。

**优先 `event` 而不是 `cap`。** 控制项说出了发生过什么；缩尾是改数据并把它藏起来。
只有客户同意"这个值本身不可信"才用 `cap`，而且呈现时必须明说响应被改了。

**`start` / `end` 是顶层的 yyyymm 整数**，不是字符串、不是嵌套在 `window` 里的。
一个已接受但没有窗口的处置对拟合零影响——验收会点名它，因为那是同一个 bug 换了张脸。

## 收尾

`anomalies.yaml` 里的每一张卡在客户裁定之后都必须是 `accepted` 或 `rejected`。
验收会点名还停在 `pending` 的卡片，也会把文件里的卡片数和引擎真正读进去的行数对一下——
读不进去的卡等于客户白裁定了一次，而这件事以前是静默发生的。

然后 `signoff.md`。卡片在客户裁定之前都只是提名。
