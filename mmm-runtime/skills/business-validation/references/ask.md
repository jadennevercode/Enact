# 对着图提问，和把图改一下

图册是**看**的地方，对话是**问和改**的地方。这一份说清楚哪些事在哪里发生。

## 三种请求，三条路

| 顾问说的话 | 本质 | 怎么做 |
|---|---|---|
| "把渠道拆开看" / "只看华东" / "换成季度" / "钻到抖音下面" | **看法变了，数没变** | 页面里就能切。告诉他点哪儿，别重跑 |
| "2025 年 O2O 为什么掉了" | **要解释，要证据** | 跑 `validation.read`，用它返回的数字作答 |
| "把这个异常记成平台砍了合作" / "客户否掉了这条" | **产生了状态** | 写进对应的产出物，交编排层确认 |

把第一种当成第三种做，就是每切一次维度重跑一遍全流程；把第二种当成第一种做，
就是对着图凭印象讲故事。

## 答问题：先读，再答

```bash
~/.local/bin/mmm tool validation.read --workspace <工作区> \
  --card "品牌传播" --level "l5=抖音,l6=头部达人" --grain quarter --channel MT
```

卡片名是它的 `L1›L2›L3` 路径，给一段能唯一命中的文字也行。不确定叫什么就先 `--list`。

筛选参数和页面上的控件一一对应，**作用域也一样**：

- `--brand` / `--channel` / `--region` / `--grain` 作用于全图，销量底图跟着动
- `--source` / `--level` / `--indicator` 只作用于叠加层，销量底图不动
- `--indicator` 不给 = 这张卡的默认六条，**不是全部**

它返回这条卡在这个筛选态下的数字：首末与变化幅度、峰谷及其期间、单期最大变动、
最长单向连续、缺口、以及与响应的相关系数，外加年度表。

**答案只能用这里出现的数字。** 说不出出处的数字就不说——这不是谨慎，是因为一个记错的
月份会被客户当成事实带走。

这个工具和页面走的是**同一个归约内核**，所以顾问在会上念出来的数，和客户此刻在页面上
按同样条件看到的数，不可能不一样。这不是两边都很小心，是两边根本就是同一份算法。

名字对不上时它判失败、不会挑一条最像的给你。这时把 `--list` 的结果摆出来让人指，别猜。

## 改图：分清楚改的是什么

**只是换个看法** —— 页面里已经有了：时间粒度、品牌/渠道/区域、数据来源、L4–L8 下钻、
指标多选、图例显隐、轴范围、时间刷选、同月对比。直接告诉顾问点哪里。这类操作是瞬时的，
不该占一个来回。

**要看一个页面切不出来的东西** —— 比如换了指标的汇总口径、改了响应变量、加了一个新的
下钻层级 —— 那不是改图，是改上游。走对应的步骤，并且要留痕。

**改完上游要重出页面**：

```bash
~/.local/bin/mmm tool validation.panel  --workspace <工作区>
~/.local/bin/mmm tool validation.facts  --workspace <工作区>
~/.local/bin/mmm app charts book --workspace <工作区>
```

然后告诉顾问刷新页面。**不要口头描述一张没有画出来的图**——描述出来的图没有出处，
也没法给客户看。

## 页面上那两个按钮

每张卡的解读区块右上角有 `Ask about this chart` 与 `Regenerate`。**它们背后没有后端，
也不假装有** —— 各自展开一段可复制的文字：

- **Ask** 给的是这张卡在**当前筛选态**下的那条 `validation.read` 命令。顾问把它复制到
  对话里跑，拿返回的数字作答 —— 这正是上面那张表第二行说的做法。
- **Regenerate** 给的是重出流程，外加一句：解读写在 `artifacts/s2/chart-analyses.yaml`，
  改页面没有用。

## 一件不能做的事

**页面里不做签核。** 客户否掉了哪条指标只存 `artifacts/s2/signoffs.yaml`，页面上没有
任何可提交的控件。

理由是这件事最不能有两个真相源：客户在页面上勾了、文件里没有，或者反过来，这种分叉在
下一次重出图册时才会暴露，而那时人已经以为记下来了。走 `signoff.md`，由编排层记录。
