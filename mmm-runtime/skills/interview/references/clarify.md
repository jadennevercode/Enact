# 访谈的澄清点

**先读完因子树、项目档案、知识包、材料索引、`inputs/org-structure/` 再问。**
里面已经写清楚的，不要问——问了就说明没读，这是最伤信任的一种废话。

五条一次问完，按影响面排序。形式固定：先说读到了什么、缺的是什么，
再给候选 + 推荐 + 每项的后果。

**只问你这次要用的那个能力需要的。** 五个能力各自独立：只做「整理纪要」的时候，
澄清 1/2/3 和这次没关系，问它们是在浪费人的注意力。对应关系：

| 你要用的能力 | 要问的澄清 |
|---|---|
| 1 · 起草提纲 | 1、2、3 |
| 2 · 先答一版 | 无（提纲已经定了形状） |
| 3 · 整理纪要 | 4、5 |
| 4 · 提因子改动 | 无 |
| 5 · 提洞察与假设 | 无 |

## 1 · 访谈对象名单与档期

**什么时候问：** `inputs/org-structure/` 是空的时候。客户给过组织架构图或关键受访人
名单的，按它分组，**只问档期**——名单已经在手上还去问一遍，是最伤信任的一种废话。

那里是空的才走这一条。因子树的 `owner` / `team` 字段和材料索引里的组织信息只能给出
一个草稿：它们记的是"谁提出了这个因子"，不是"谁能回答关于它的问题"。而且客户的实际
组织和三层模板经常对不上——有的客户没有市场洞察，有的把渠道市场并在销售里。

**为什么非问不可：** 访谈对象的数量决定题量和提纲的形状。而提纲的第一用途是让客户排会：
没有对象、没有时长、没有题数，这份提纲就排不了会。

```
【澄清 1/5】访谈对象名单
读到：inputs/org-structure/ 是空的；因子树上有 6 个团队署名，
      材料索引里提到市场部、销售部、财务部。

  A. 按三层结构全量出（推荐）—— 高层 / 管理层 / 执行层，各团队一节，客户自己删。
     代价：会出几个客户其实没有的团队，删掉的成本很低。
  B. 只对客户点名的团队出 —— 提纲短。
     代价：漏掉的那一层会在收数时变成"没人知道这个指标在谁手里"。
  C. 你把组织架构图或关键受访人名单放进 inputs/org-structure/ —— 我按它排。
     代价：多一步上传，但省掉后面所有关于"这个人管什么"的往返。
```

## 2 · 有没有独立的数据团队

**什么时候问：** 每次，单独问，不要混在上一条里。

**为什么非问不可：** 数据类问题是提纲里最大的一块（一个因子四问，几十个因子就是几百题）。
它们的去处只有两种：一个统一的数据团队，或者分散挂到各业务团队。选错，提纲要重排。

```
【澄清 2/5】数据类问题问谁
  A. 有独立的数据/IT 团队（推荐，如果确实有）—— 数据题全部归到这一节，一次问完。
  B. 没有，数据散在各业务团队 —— 数据题按 L3 拆进对应团队那一节。
     代价：每一节都变长，但问的人是真正知道答案的人。
```

## 3 · 数据类问题问到多细

**什么时候问：** 被采纳的因子行数 × 4 明显超过一场会能问完的量时（一般 40 行就到了）。

**为什么非问不可：** 一场 90 分钟的会问不完 168 题。但删题会留下"没人问过口径"的因子，
到收数才发现。

```
【澄清 3/5】数据题的出法
  A. 全量四问，按预答置信度标出现场必问的重点（推荐）
     —— 提纲完整，现场只过重点题，其余作为书面清单请数据团队回填。
     代价：提纲很长，要提前说明"这不是要在会上逐条问完的"。
  B. 只对预答置信度低的因子出全四问 —— 会议时间省下来了。
     代价：没被问到的因子在收数时没有口径，等于把风险推到最贵的时候。
  C. 按 L3 而不是按因子行出题 —— 题量降到四分之一。
     代价：丢掉行与行之间的口径差异，而口径差异正是访谈要问的东西。
```

## 4 · 纪要以什么形式回来

**什么时候问：** 每次，而且要在人去准备之前问——不然会收到一堆音频然后卡住。

```
【澄清 4/5】纪要的形式
  A. 文字纪要（推荐）—— 直接可读，可以逐段挂题号。
  B. 逐字转录稿 —— 信息最全，但噪声大，要先归纳成纪要。
  C. 录音 —— 这里不做转写。必须先由人转成文字，否则这一步走不下去。
```

## 5 · 一场访谈没覆盖到的问题怎么算

**什么时候问：** 每次。这是"空是一个发现"的具体落点。

```
【澄清 5/5】没问到的题怎么处理
  A. 逐条列出 + 为什么没问到 + 下一步（推荐）
  B. 不提 —— 因子树会看起来被访谈验证过，其实没有。
```

选 A 时，纪要里的「## 没覆盖到」就是必填段落，不是可选的。提纲上的每一题合起来
要么在某个段标签里，要么在这一段里——`minutes_cover_outline` 会把两处都没有的题号
原样报出来。

## 问不到人的时候

按推荐项走，在提纲的 `meta` 里写清楚：问题、采用的答案、`assumed: true`、以及理由。
交付时主动说出来："这五项里有两项没问到人，我按推荐走了，分别是……"

假设本身不是问题，沉默才是。
