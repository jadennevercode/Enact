# 统计检验的澄清点

**先读完签核结论、因子映射和打分结果再问。** 已经在里面的不要问。一次全部问完。

**合成公式与档位不问。** 加法四档与乘法三档的分歧已经裁定：跟随代码，三项相乘、三档、
**总分 ≥ 0.5 为良好**（验收表里 0.5 同时落在两档，客户裁定它归验收通过，与数据质量评分表
的同一处歧义按同一条裁决处理）。理由与对客户的统一话术见 SKILL.md 的「口径」。
把它拿来当选择题，是在让人重新决定一件已经定了的事。

---

## 1 · 哪些因子业务上不可替代（岔路）

**什么时候问：** 有落在 0.5 分档的行——波动系数在 0.05–0.1、或相关系数绝对值在 0.1–0.3。

**为什么非问不可：** 规则原文是"因子多且业务重要性弱可忽略；因子少或重要性强则入模"。
"业务重要性"这四个字只有人给得出。

```
【澄清 1/4】哪些因子是不可替代的
读到：7 个指标落在 0.5 分档，分属 5 个因子。

  A. 给一份不可替代清单 —— 清单内的 0.5 分行保留，清单外的剔除。
  B. 全部保留 —— 模型更全，但会带进几个几乎不动的变量，稀释自由度。
  C. 全部剔除 —— 模型更精简，代价是有因子会一个指标都不剩（会触发因子级预警）。
```

## 2 · 观测期够不够（缺失）

**什么时候问：** 有指标的观测月数少于 12。低于这个数，三项检验对它不再说明任何事。

```
【澄清 2/4】观测月数不足 12 的指标怎么处理
读到：3 个指标只有 7–9 个观测月。

  A. 仍然打分并标注证据不足（推荐）—— 漏斗计数保持诚实，人能看见它们的存在。
  B. 直接剔除 —— 计数会对不上，模型输入那一步的收口表会少几行没人解释。
```

## 3 · 高共线性指标怎么处置（越界）

**什么时候问：** 有共线性指标 ≥ 10 的行。

四条路逐条定：**降维** / **合并同类** / **剔除** / **保留但知情**。

**成组定，不逐行定。** 共线性说的是"这一组"：拿掉一个，其余每一个的值都会变。
沿着排序列表一行一行地砍，会砍掉三个变量，而实际上砍一个就够了。
定完一组之后重跑打分，把新的共线性值再摆一遍。

## 4 · 某因子的指标全部不达标时找不找替代（缺失）

```
【澄清 4/4】<因子名> 的全部候选指标都不达标
读到：该因子 2 个候选指标的波动系数都 ≤ 0.05，序列基本不动。

  A. 预警并回流业务理解找替代指标（推荐）—— 这是明规则；模型才不会对这块生意失语。
     代价：回流要重开上游，工期往后拖。
  B. 该因子不入模，在交付说明里预警 —— 因子树上留一个洞，建模阶段的结论不覆盖它。
```
