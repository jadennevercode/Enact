# OLS 预验证

先和客户定这次用哪些数据、切成几个模型，再定参数，然后拟合。每个模型对象是一个格子，
**它全部存活的驱动变量一次性进同一个模型**。**这个 Skill 只产出这一份交付物。**

## 它是"报告 + 逐行裁决"，不是"自动选指标"

平台原本用这一步选变量：同一个 L4 有多个候选指标时，选跑出来最贴合业务区间的那一个，
最多试 96 次拟合。**这套做法已被整个删掉**，理由值得照抄：
**一条基准是用来比对结果的，绝不能是变量集合被调向的目标。**
一个被拟合到与基准吻合为止的模型，检验的是那个搜索，不是这个模型。
所以现在的问题是"**每个变量对响应做了什么**"，而不是"哪个指标组合读起来最好"；
选指标的动作实际落在**逐行采纳 / 否决**上。对客户要把这一点说清楚。

**开始前：** 读 `../../shared/conventions.md` 定位工作区，确认统计检验已确认。
数据阶段的工具从统一入口进：`~/.local/bin/mmm tool <id> …`。

## 第 0 步 · 澄清（先读完再问）

先读完统计检验结论、签核结论、行业知识包，**已经写在里面的不许问**。详见 `references/clarify.md`。

| 澄清点 | 什么时候必须问 | 推荐项 |
|---|---|---|
| 响应是货币还是销量；销量的话单价多少 | **每次必问**。没有单价，投资回报不可与行业带比较 | 问出单价 |
| 区间取客户行业包还是参考库 | 行业不是饮料/快消时必问 | 客户行业包；取不到报"无可比区间" |
| 模型对象怎么切 | **在 `plan` 步问**，工具把每种切法要按住几个变量都算出来了 | 可行的最细那一档 |
| 区间反常识的因子怎么办 | 出现红灯行时，逐条问 | 无默认，见下三种形态 |
| 控制项与变换参数 | **在 `params` 步问**，默认值可以直接用 | 按观测数自动缩放 |

## 硬规矩

**每个数都来自一次真实的工具运行。** 系数、t 值、拟合优度、贡献度、投资回报全部来自
`data/derived/ols-fit.json`，文档要声明它读的是这份计算结果。
**逐字照抄：不四舍五入、不换单位、不心算、不重算。** 手写的拟合优度和真的长得一模一样。

**响应不是货币时，投资回报不做区间检查。** 行业带是货币比率，"箱/元"和它不可比；拿它去判越界
然后提议剔除，是把错误答案用正确答案的口吻说出来。这种情况区间状态恒为"无区间"。

**反常识判据是红黄绿灯，不是在区间内 / 不在两个值。** 偏离 < 30% 是黄灯（进裁决，推荐保留）；
**≥ 30% 是红灯，回流业务校验重审假设**。1.35 对 0.8~1.3 和 13 对同一条带，要的动作是相反的。

**拟合失配先减控制项，不走剔除指标那条路。** 基线占比 > 100%（控制项吸收的销量超过全部实际销量）
或付费驱动系数反号时**先减少傅里叶阶数或关掉趋势重跑**，再谈剔除被标记的指标——
是拟合而不是数据在产生那些疯狂贡献，这时候剔指标是治错了病。

**自由度限制与共线性预筛不是对指标的判决。** 超出月数所能识别的驱动位**不勾选但保留在表上并写明
理由**；设计矩阵共线性 > 100 的驱动在拟合前剔除，控制项永不剔除。说成"模型否掉了这个指标"，
会让人去重新收一份本来没问题的数据。

**人的裁决压过重拟合**，带"人裁决"标记的行保留人的处置与备注。**被拒的行不许消失**：
拒绝会把该指标排除，下一次拟合就没有它的记录，把树里不再提到的行删掉等于删掉那条把它移走的
裁决本身，指标会无声地走回来。

**判据不是参数。** 显著性阈值、最少残差自由度、共线剔除线固定，列在产出里给客户看但不开放——
被判的一方能调的判据就不再是判据。红灯线是唯一可按项目挪的一条，代价是写清楚为什么。

**粒度是人定的，工具只算代价。** 切得越细能回答的问题越多、每个模型能识别的驱动越少，
两个产品是不是一回事算术定不了。推荐的是**可行的最细那一档**，不是按住最少的那一档。

**拟合要收敛成不动点。** 保存一次拒绝会重新拟合，而判读是从**那次**拟合得出的——
一个因为邻居离开而越界的因子，是在包含它的模型被渲染之后才被拒的。跑第二遍。
**不可复议：** 上一层已经裁过的（映射层拒、质量/签核/统计层拒、没进这次拟合）不参与本步裁决。

## 说话的规矩

1. 先说结论，再说依据，不铺垫。
2. 只说业务语言：说「确认」「检查项」「交付物」「计算结果」，不说 gate、predicate、artifact。
3. 每步三句话内交代：做了什么 / 结果是什么 / 需要你什么。
4. 要人拍板时永远给选择题：候选 + 推荐 + 每项后果。红灯行逐条，绿灯行成批。
5. 数字要报出处。说不出出处的数字就不说。
6. 拿不准就问。"大致""可能""建议进一步确认"通常是该问没问留下的痕迹。
