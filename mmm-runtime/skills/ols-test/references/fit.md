# 步骤 fit —— 组变量、拟合、算区间（M + A）

```bash
~/.local/bin/mmm tool ledger.derive   --workspace <工作区>
~/.local/bin/mmm tool ols.propose     --workspace <工作区>
~/.local/bin/mmm tool ols.fit         --workspace <工作区> --purpose "<为什么跑这一次>"
```

`ledger.derive` 永远先跑。它写出 `data/derived/selection.json`——**唯一那份已解析的选择**
（排除集、勾选集、响应、参数）。`ols.propose` 读它，写 `artifacts/s2/ols-config.yaml`。

行业区间的批量比对在下一步 `review.md` 里用 `ols.scorecard` 一次做完，不在这一步跑。
`knowledge.range` 是查单条用的手工工具（`--l4` 必填），核对某一个因子的基准从哪来时才用，
不是这一步流水线命令的一部分。

## 一次拟合要先说明它是为什么跑的

`--purpose` 必填，而且要在看到结果之前写下来。允许多次拟合是有用的——
拟合失配就是靠改控制项重跑修的——但**反复重跑然后留下最好看的那一次，
就是这一步当初删掉的那套指标搜索，只不过从挑变量升级成了挑运行**。

每次运行拿一个编号，完整结果留在 `data/derived/ols-runs/<编号>.json`，
`data/derived/ols-fit.json` 同时是运行索引和本次结果。**所有运行都保留**，
采纳与否都在历史里。采纳某一次的理由只有三类：修正了拟合失配、客户改了决定、
修掉了口径或数据错误。"拟合优度更高""更贴合区间"会被直接拒。

## 唯一那份选择

这一步的拟合、重拟合、模型输入表，读的都是它。**在调用处重新推导一次，
正是当初训练跑在没过滤的数据上的原因**：拟合跑完了，报了一个拟合优度，
而里面悄悄含着三层已经否掉的指标。

不要编辑 `selection.json`。它和账本对不上时，做法是重跑 `ledger.derive`。

## 模型对象

按 `plan` 步选定的切法来，不是写死渠道 × 品牌。id 里 `*` 表示这一维不切：
`*::*` 全体、`*::某品牌` 不分渠道、`MT::某品牌` 渠道 × 品牌。**它的编号在下游是不透明的**，只有引擎内部解析。

一个格子要同时有响应和驱动才成立。有响应没驱动的格子（例如竞品的售出）**逐个点名跳过**，
其余照跑。**一个对象拟不出来只报它自己的错，另外 N×M-1 个照走。**

**没有渠道不是缺陷。** 渠道类型为空的行是全国行：为全国买的媒体，共享进**每一个**对象。
要求每行必须有渠道，正是分渠道建模把全国媒体整个删掉的原因——每个模型的驱动从 17 条掉到 6 条，
而拟合没报任何错。没有响应的品牌是市场环境，它的行也共享进每个对象。

## 组候选变量：全变量一次进，没有搜索

每个对象把它全部存活的驱动变量一次性放进同一个模型。**唯一能把一个变量拿下来的是可识别性：**

| 原因 | 判据 | 怎么报 |
|---|---|---|
| 自由度 | 可负担驱动数 = max(1, 月数 − 控制项数 − 1 − 10) | **不勾选但保留在表上**，按与响应的相关性排序，写明"这是自由度限制，不是对指标的判决" |
| 共线性 | 设计矩阵共线性 > 100 | 拟合前剔除，报出它的值。**控制项永不剔除** |

另外两个数只作**告警注记**，不再决定勾选：相关性绝对值 < 0.1（信号很弱）、共线性 > 10（与其余变量共线）。

## 控制项

趋势 + 傅里叶季节项 + 月度哑变量 + **每个已接受的 `event` 异常窗口一列 0/1**。恒定的控制列剔除。
`cap` 异常在拟合时对响应缩尾。**提名状态和被拒的卡片什么都不贡献。**

按观测数缩放：月数 < 24 整段关掉季节项；< 36 傅里叶阶数封顶 1 阶；进入建模最低 12 个月。

## 变换

几何 adstock（`a[t] = x[t] + decay·a[t-1]`，0 ≤ decay < 1）+ Hill 饱和
（`x^slope / (x^slope + half^slope)`），随序列长度缩放。

## 拟合

最小二乘 + 截距。输出系数、标准误、t 值、p 值、拟合优度、调整拟合优度、平均绝对百分误差、
残差自相关统计量、共线性、残差。**观测数 ≤ 参数数 + 1 直接报错，不产出假结果。**

`|t| ≥ 2.0` 视为显著。拟合必须留下至少 10 个残差自由度，每个变量花掉 1 个。

## 贡献度

```
基准位：花费类指标 → 0；非花费类 → 窗口内最小值（最小值 ≤ 0 时仍取 0）
贡献度 = Σ 系数 ×（x − 基准位） / Σ 实际响应   （× 100 得百分点）
```

基准位以下的部分归入基线；控制列整体折进基线。
**恒等式必须成立：基线占比 + Σ 各驱动贡献 = 100%。** 不成立就是分解错了，不是舍入。

产出必须写明基准位口径（`vs zero` 还是 `vs its lowest month`）——同一个系数在两种基准下贡献差很多。

## 投资回报

```
增量 = 系数 × Σ 变换后的 x
响应是货币          → 增量就是增量收入
响应是销量 且有单价 → 增量 × 单价
响应是销量 无单价   → 单位是 销量/花费
分母：该指标自身是花费 → 用它自己的花费
      否则             → 用该 L4 的花费序列，**产出里写明借了谁的分母**
```

**单位不是货币时，投资回报的区间状态恒为"无区间"。** 这条是硬规矩，见 SKILL.md。

## 区间与红黄绿灯

取区间的优先级、精确匹配规则见 `clarify.md` 第 2 条。判定：

```
没有带 / 值为空       → 无区间（noBenchmark）—— 诚实状态，不是通过
带内                  → 绿灯
带外，偏离 < 30%      → 黄灯：进裁决，推荐保留
带外，偏离 ≥ 30%      → 红灯：推荐否决，并提示回流业务校验重审假设
```

偏离按它突破的那一侧带沿计算：`|值 − 带沿| / |带沿| × 100%`。

## 红旗，必须点名

| 条件 | 含义与处置 |
|---|---|
| 基线占比 < 0 | 分解崩了 |
| **基线占比 > 100%** | **拟合失配：控制项吸收的销量超过了全部实际销量。先减控制项重跑** |
| **付费驱动系数为负** | **拟合失配（同上）。先减控制项，再谈剔除指标** |
| 拟合优度 < 0.85 | 目标带 0.85–0.95 |
| 平均绝对百分误差不在 5–15 | — |
| 残差自相关统计量不在 1.5–2.5 | — |
| 驱动列共线性 > 10 | 取最大者报出 |
| 设计矩阵共线性 > 100 | 该驱动在拟合前被剔除 |

**拟合失配的处置顺序是硬规矩**：先减控制项（减少傅里叶阶数或关掉趋势），**再**谈剔除被标记的指标。

## 文档

`artifacts/s2/ols-test.md` 从拟合结果渲染，元信息块声明读的是它。逐对象说：
拟合在几个月上、拟合统计量、关键驱动与它们的贡献、以及任何被留出的变量和理由。
然后跨对象说模型在哪里不一致——一个在某渠道显著、在另一个渠道根本不在的因子，
是这份文档里最有用的一段。

**关键驱动是算出来的**（显著驱动按贡献排序）。你解释这份清单为什么是这样，**你不挑它**。

## 跑的是参考数据集时

产出与呈现都要明说"这次拟合跑的是参考数据集，不是项目数据"。

## 空也是结论

一个没产出拟合的对象、一个估不出来的系数、一个月数比预期少的模型——写下来，连同原因。
被跳过的对象是交付物的一部分，不是省略。
