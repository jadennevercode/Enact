# OLS 预验证的澄清点

**两条已经搬走了。** 「模型对象怎么切」在 `plan` 步问，工具会把每种切法要按住几个变量
先算出来（见 `plan.md`）；「控制项预算」在 `params` 步问，默认值直接可用（见 `params.md`）。
留在这里的是拟合与判读阶段才问得出来的三条。

**先读完统计检验结论、签核结论与行业知识包再问。** 已经在里面的不要问。一次全部问完。

## 1 · 响应是货币还是销量；销量的话单价是多少（缺失，每次必问）

**为什么非问不可：** 没有单价，投资回报的单位是"销量/花费"（例如 箱/元），
**与行业投资回报带（货币比率）完全不可比，不许拿去判越界**。

```
【澄清 1/5】响应的口径与单价
读到：响应是本品销量（箱，月度）。行业知识包里的投资回报带是货币比率。

  A. 给出单价（推荐）—— 投资回报换算成货币，可以做区间检查。
  B. 不给单价 —— 投资回报单位是 箱/元，本轮不做投资回报区间检查，只检查贡献度。
     代价：反常识判据少了一半的证据。
```

选 B 时产出里的投资回报区间状态恒为"无区间"，**不是"通过"**。

## 2 · 区间取客户行业知识包还是参考区间库（冲突）

优先级是定死的：**行业知识包精确匹配 (L4, 指标) → 行业知识包仅 L4 → 参考区间库（仅饮料/快消）**。
都取不到就是"无可比区间"。

```
【澄清 2/5】拿谁的区间判这个客户的因子
  A. 客户行业知识包（推荐）—— 是这个客户这个行业的带宽。
  B. 参考区间库 —— 它自述"区间为饮料案例示例，新项目须替换"。
     代价：行业不是饮料/快消时，等于用别人的带宽判这个客户的因子，并据此提议剔除。
```

**参考库的因子名只许精确匹配**（大小写与空白归一化后相等）。
平台曾用双向子串匹配代替查表，凭空造出库里从来没有的基准：`Connected TV` 匹配到 `TV`、
`OOH Billboards` 匹配到 `OOH`、`价格变动率` 匹配到 `价格变动`。每一个都造出一条带，
因子据此被判、被标记、并可能被剔除——全都源于一个名字里含着另一个名字。
**一条基准要么是这个因子的基准，要么比没有基准更糟。**

## 3 · 模型对象怎么切 —— **已移到 `plan` 步**，见 `plan.md`

<details><summary>原文留档</summary>


**什么时候问：** 某个格子的月数撑不住自由度，或者一个格子里混着行为完全不同的渠道。

```
【澄清 3/5】按什么切模型对象
  A. 渠道 × 产品（推荐，也是默认）
  B. 更粗（例如只按渠道）—— 每个格子月数更足。
     代价：把行为完全不同的产品混在一起，系数是个平均值。
  C. 更细 —— 代价：每个格子月数不够，自由度撑不住，很多驱动位只能空着。
```

格子数直接决定几个模型、每个模型能带几个变量。

</details>

## 4 · 区间反常识的因子怎么办（越界，逐条问红灯行）

**三种形态，正确动作各不相同**——这一条是本步的核心判断：

| 形态 | 正确动作 |
|---|---|
| **符号反了**（付费驱动系数为负） | **先查拟合失配，不是先剔指标。** 减控制项重跑 |
| **量级离谱**（贡献度远超其带若干倍） | 先查基准位与分母，再查区间是不是过时了 |
| **方向与客户确认的假设相反** | **回流业务校验重审假设** |

```
【澄清 4/5】<因子名> 的投资回报 <值>，落在 <带> 之外，偏离 <n>%（红灯）
  A. 认为区间过时 —— 保留该因子并记理由。
  B. 认为拟合有问题 —— 先减控制项重跑，再看它是否还越界。
  C. 认为业务假设有问题 —— 回流业务校验重审假设。
```

## 5 · 控制项预算 —— **已移到 `params` 步**，见 `params.md`

<details><summary>原文留档</summary>


**什么时候问：** 月数少，或者基线占比 > 100%、付费驱动系数反号。

```
【澄清 5/5】控制项给多少
  A. 按观测数自动缩放（推荐）—— 月数 < 24 关掉季节项，< 36 傅里叶阶数封顶 1 阶。
  B. 人指定 —— 出现拟合失配时先减阶数或关掉趋势。
```

月数少时"趋势 + 完整傅里叶"会把真实销量吸进基线，症状就是基线占比 > 100% 和付费驱动反号。

</details>
