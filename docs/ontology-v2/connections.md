# Sources 数据与行动连接规格

Sources 按知识、数据、系统行动能力区分连接。同一个系统可以支持多种能力，但浏览和调用权限分别显示。连接成功后主动发现可访问资源；数据连接展示表、字段、类型、键与可读样例，系统连接展示 HTTP/MCP 方法、输入输出和调用说明。发现失败保留明确错误与重试入口，不显示空白的“成功”。

复用 Semantica 的原生 ingest/discovery 与既有连接注册表。Enact 负责凭据加密、用户身份、发现快照、绑定所依据的目录修订和变更检测。读取限制为目录明确声明的只读操作；一个未知 MCP operation 不会因名称像查询就获得读取权限。

绑定先以业务主体或行动说明目的，再展示数据资源、字段或系统操作映射。目录变化后重新检查绑定，不让过时参数或修改后的行动契约继续获得旧审批。执行前的 connection/credential revision 仍参与动作摘要校验。

验收：数据库发现字段与样例；OpenAPI 区分读写；MCP 保留工具 schema 和 annotations；未声明只读的调用被阻止；跨用户目录/快照隔离；连接停用与目录变化后旧绑定不能无提示执行。当前未提供凭据的 Databricks/Snowflake/SAP 等模块只显示可用连接器与配置要求，不宣称已现场验证。
