# 锚点

一个锚点是一句话在原件里的坐标。判据只有一条：

> 三个月后，拿着这个锚点，能不能在原件里翻到那句话。

翻不到的不是锚点，是一段模糊的印象。检查项 `no_inference_as_fact` 要求每条 `fact`
至少有一个同时带 `location` 与 `exact_snippet` 的锚点；`trace_complete` 在生成阶段
会顺着 alignment 一路走回来，再核一次同样的两个字段。

## 两个字段，两件事

```yaml
anchors:
  - location: "§6.2/3"                                   # 在哪儿
    exact_snippet: "金额大于等于 50,000 元：由财务控制（Controller）审批。"   # 是哪句话
```

- `location` 回答"去哪找"。它必须是原件自己的坐标体系，不是我们编的编号。
- `exact_snippet` 回答"找到之后核对哪句话"。**逐字照抄**，不缩写、不改标点、
  不翻译。中英混排原样保留：`财务控制（Controller）` 不要写成 `Controller`，
  也不要写成 `财务控制`。

两个字段互为校验。`location` 单独存在时，材料改版后你会翻到一段完全不同的文字
而毫无察觉；`exact_snippet` 单独存在时，你只能全文搜索，而全文搜索在一份
两百页的手册里会命中七处。

## 每种格式的稳定锚点

| 格式 | `location` 写什么 | 例子 |
|---|---|---|
| Markdown / DOCX / 手册 | 节号 + 条目序号，两者都写 | `"§6.2/3"` |
| PDF（有文本层） | 页码 + 页内区域或段序 | `"p.14 / 第 2 段"` |
| PDF（扫描件）、图片 | 页码 + 版面位置 | `"p.14 / 左栏中部"` |
| CSV / TSV | 行号 + 列名。行号从数据首行算起并写明表头在第几行 | `"row 4 (表头 row 1) / column tax_included"` |
| XLSX | 工作表名 + 单元格地址 | `"Sheet1!D7"` |
| 流程图 / BPMN | 节点标签或连线两端，加相对位置 | `"图/判断节点「审批通过?」否分支"` |
| 表格（文档内） | 表标题 + 行标识 + 列名 | `"术语表 / 冲销行 / 备注列"` |
| URL | URL + 访问日期 + 锚记或标题 | `"https://… (2026-09-03) #section-3"` |

**不要用行号给 Markdown 或 PDF 做锚点。** 文件加一段话，所有行号一起失效，
而失效的方式是静默的：锚点仍然指向一个存在的行，只是内容变了。节号不会。

## 图区锚点

流程图最容易出问题，因为图上没有天然的坐标。用节点自己的标签当锚点，
再加一个相对位置说明去哪找它：

```yaml
- location: "图/判断节点「审批通过?」否分支"
  exact_snippet: "否 →（图上此处连线断开，没有指向任何节点）"
- location: "图/右下角孤立方框"
  exact_snippet: "标签为「复核」，没有任何连线进出"
```

第二条的 `exact_snippet` 记的是**图上有什么**，不是**我们认为它是什么**。
"复核可能是一个漏画的审核环节"是一条 assumption，不是这条锚点的内容。
两件事混在一起，就是推断静默升格成事实的最常见入口。

## 一条陈述可以有多个锚点

同一件事被两处材料说过时，两个锚点都记，不要挑一个：

```yaml
- statement_id: fact.002
  classification: fact
  statement: 审批人不得是该分录的制单人。
  source_ids: [ev.001, ev.002]
  anchors:
    - location: "§6.2/3"
      exact_snippet: "无论金额大小，审批人不得是该分录的制单人。"
    - location: "§3.4"
      exact_snippet: "制单、审批、复核三项职责不得由同一人承担。"
```

两条互相印证，这条事实就比只有一处出处的更结实——而且以后其中一份材料改版时，
你能立刻看出另一份是否还支持它。

注意这两句话**不完全相同**：手册说的是审批人 ≠ 制单人，政策说的是制单/审批/复核
三者互斥。它们相容但不等价。如果两句话说的其实是不同的事，就该拆成两条陈述，
而不是塞进一条的两个锚点里。判断的方法：能不能只靠其中一个锚点把这条陈述讲完整。

## 锚点不是引用范围

`exact_snippet` 短到能核对、长到能自洽就够了。整节抄下来不是更保险，是更糟：
读的人无法知道这条陈述到底依据的是这一节里的哪一句。
