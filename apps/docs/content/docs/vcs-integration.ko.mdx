---
title: GitHub 및 사내 GitLab 저장소
description: 코드 및 디렉터리에서 GitHub App, GitLab HTTPS, 기업 CA와 Webhook을 설정합니다.
---

코드 호스팅 설정은 **소스 → 코드 및 디렉터리**에 통합됩니다. GitHub는 GitHub App을 사용하고, 사내 GitLab의 1단계는 관리형 HTTPS를 사용합니다.

연결 카드는 Server→API, provider→Webhook, daemon→Git remote 세 경로를 각각 표시합니다. GitLab은 만료일과 제한된 프로젝트 멤버십이 있는 Service Account를 권장합니다. API에는 `api`, Git HTTPS에는 `write_repository` token을 별도로 사용합니다. 비밀과 기업 CA PEM은 `ENACT_VCS_SECRET_KEY`로 암호화되며 브라우저 API에 반환되지 않습니다.

관리 작업에서는 `enact repo push`로 daemon의 임시 저장소 범위 자격 증명을 사용해 push한 뒤 `enact repo change-request --title "…"`로 Enact Server에서 PR/MR을 만듭니다.

자체 배포에서는 `ENACT_VCS_INTEGRATION_ENABLED=true`, base64 32-byte `ENACT_VCS_SECRET_KEY`, 전체 Webhook URL을 위한 `ENACT_PUBLIC_URL`을 설정하세요. TLS 검증은 끌 수 없습니다. GitLab Outbound requests에서 Enact Webhook host/IP만 허용하고 Merge request 및 Pipeline event를 등록하세요.

GitHub App에는 Contents와 Pull requests 읽기/쓰기, Checks와 Commit statuses 읽기 권한이 필요합니다. URL만 저장된 기존 저장소는 ‘설정 대기’로 중지되며 연결을 지정하기 전에는 daemon에 전달되지 않습니다. SSH는 2단계입니다.
