---
title: GitHub and enterprise GitLab repositories
description: Configure GitHub App, enterprise GitLab HTTPS credentials, private CA trust, and webhooks.
---

All code-hosting configuration now lives in **Sources → Code & directories**. GitHub uses a GitHub App. Phase one supports managed HTTPS access for self-hosted GitLab; SSH is a separate second phase.

The connection card tests three independent paths: Enact Server to the provider API, provider to Enact webhook, and each Enact daemon to the Git remote. An API success does not imply webhook delivery or Git read/write access.

For GitLab, prefer an expiring Service Account limited to the required projects. Configure two secrets: an API token with `api` scope for browsing and merge-request operations, and a Git token with `write_repository` for HTTPS clone/push. Secrets and the optional enterprise CA PEM are encrypted with `ENACT_VCS_SECRET_KEY` and are never returned by browser APIs.

Inside a managed task, use `enact repo push` to push the current branch through the daemon's temporary repository-scoped credential helper, then `enact repo change-request --title "…"` to create the pull or merge request through the Enact Server.

Enable self-hosted integration with `ENACT_VCS_INTEGRATION_ENABLED=true`, set a base64 32-byte `ENACT_VCS_SECRET_KEY`, and set `ENACT_PUBLIC_URL` so Enact can display the complete webhook URL. Keep TLS verification enabled. A connection-level PEM CA is added to the system trust store for API and daemon Git traffic.

GitLab administrators may need to allow only the Enact webhook host/IP under **Admin → Settings → Network → Outbound requests**. Register Merge request and Pipeline events with the one-time webhook secret.

GitHub App permissions are Contents and Pull requests read/write, plus Checks and Commit statuses read. Enact mints short-lived, single-repository installation tokens.

Legacy URL-only repositories are retained as disabled **Pending configuration** rows until an admin binds them to a connection. Webhooks are processed only for enabled repositories bound to the receiving connection.
