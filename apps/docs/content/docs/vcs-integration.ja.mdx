---
title: GitHub と企業 GitLab リポジトリ
description: コードとディレクトリで GitHub App、GitLab HTTPS、企業 CA、Webhook を設定します。
---

コードホスティング設定は **ソース → コードとディレクトリ** に集約されました。GitHub は GitHub App、企業 GitLab の第1段階は管理された HTTPS を使用します。

接続カードは Server→API、provider→Webhook、daemon→Git remote の3経路を別々に表示します。GitLab では期限付き Service Account を推奨します。API 用に `api`、Git HTTPS 用に `write_repository` の2つの token を設定してください。秘密と企業 CA PEM は `ENACT_VCS_SECRET_KEY` で暗号化され、ブラウザ API には返りません。

管理対象タスクでは `enact repo push` で daemon の一時的なリポジトリ限定認証情報を使って push し、`enact repo change-request --title "…"` で Enact Server から PR/MR を作成します。

自部署では `ENACT_VCS_INTEGRATION_ENABLED=true`、base64 32-byte の `ENACT_VCS_SECRET_KEY`、完全な Webhook URL 用の `ENACT_PUBLIC_URL` を設定します。TLS 検証は無効化できません。GitLab の Outbound requests では Enact Webhook の host/IP だけを許可し、Merge request と Pipeline event を登録します。

GitHub App は Contents と Pull requests の読み書き、Checks と Commit statuses の読み取り権限が必要です。旧 URL のみのリポジトリは「設定待ち」で停止し、接続を割り当てるまで daemon に渡されません。SSH は第2段階です。
