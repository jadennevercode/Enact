에이전트는 파일을 만들어 냅니다. 보고서, 다이어그램, 내보낸 데이터, 스크린샷. 그 파일은 실행을 시작한 이슈나 채팅에 남습니다. 그 자리에서 맥락과 함께 읽기에는 알맞지만, 일주일 뒤에 찾아내기에는 알맞지 않습니다.

**아티팩트**는 같은 파일을 워크스페이스 전체에서 보는 화면입니다. 사이드바에서 열 수 있고 주소는 `/{slug}/artifacts`입니다.

## 화면 구성

왼쪽은 트리, 오른쪽은 선택한 항목의 상세입니다.

| 단계 | 내용 |
|---|---|
| **폴더** | 파일이 나온 이슈이며 이슈 키와 제목으로 표시됩니다. |
| **행** | 아티팩트 하나 — 파일 이름과 그 모든 버전입니다. |
| **상세** | 선택한 아티팩트의 각 버전이며, 최신순으로 정렬되고 개별로 내려받을 수 있습니다. |

[채팅](/chat)에서 만들어진 파일도 여기에 함께 나열됩니다. 이전에는 모아 둘 곳이 없어 어떤 목록에도 나타나지 않았습니다.

## 버전

에이전트 실행은 파일을 덮어쓰지 않습니다. 작업을 다시 실행하면 새 파일이 업로드되고 이전 파일은 그대로 남습니다.

두 파일은 **같은 이슈에 속하고 파일 이름이 같을 때** 하나의 아티팩트의 버전이 됩니다. 행에 표시되고 그냥 내려받았을 때 받는 것은 가장 최신 버전이며, 이전 버전은 상세 화면에서 계속 확인할 수 있습니다. 서로 다른 두 이슈가 각각 `report.pdf`를 만들었다면 이는 두 개의 아티팩트이지 한 파일의 두 버전이 아닙니다. 파일 이름에 의미를 주는 것은 이슈입니다.

## 파일 찾기와 열기

검색은 파일 이름과 폴더로 트리를 걸러 내며, 일치가 남아 있는 폴더는 스스로 펼쳐집니다. 검색 범위를 좁혀도 상세 화면이 설명하는 파일이 바뀌지는 않습니다.

상세 화면에서는 Enact가 브라우저에서 렌더링할 수 있는 파일을 미리 보고, 원하는 버전을 내려받고, 파일이 나온 이슈로 이동할 수 있습니다.
