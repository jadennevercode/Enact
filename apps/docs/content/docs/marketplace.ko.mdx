마켓플레이스는 이 배포의 워크스페이스들이 공개한 기능 목록입니다. [스킬](/skills), 에이전트 템플릿, MCP 서버 항목이 있습니다. 하나를 설치하면 내 워크스페이스에 **사본**이 만들어지고, 이후에는 직접 작성한 것처럼 수정할 수 있습니다.

## 공개할 수 있는 것

| 종류 | 함께 전달되는 것 | 전달되지 않는 것 |
|---|---|---|
| **스킬** | `SKILL.md`와 모든 참고 파일 | 없음 — 스킬은 글이며 작성된 그대로 공개됩니다 |
| **에이전트 템플릿** | 이름, 설명, 지시문, 모델과 추론 설정, 함께 제공되는 스킬, 필요한 MCP 서버 | 환경 변수, 런타임 연결, 런타임 설정, 누가 호출할 수 있는지에 대한 설정 |
| **MCP 서버** | 모든 자격 증명을 제거한 서버 항목 | `env`와 헤더 값, 그리고 공개로 표시하지 않은 URL |

<Callout type="warn">
공개할 때 브라우저에서 내용을 업로드하는 일은 없습니다. 내 워크스페이스의 항목 하나를 지정하면 서버가 그것을 읽어 자격 증명이 담긴 필드를 모두 제거한 뒤 결과를 저장합니다. 그래서 이 제외 처리를 믿을 수 있습니다.
</Callout>

## 공개하기

사이드바에서 마켓플레이스를 열고 **공개**를 선택하거나, 스킬 페이지, 에이전트 메뉴, **설정 → MCP**의 각 행에 있는 공개 동작을 사용하세요.

메타데이터 외에 두 가지를 정해야 합니다.

- **볼 수 있는 대상.** `이 워크스페이스만`은 팀 내부 라이브러리입니다. `공개`는 이 배포의 모든 워크스페이스에 닿습니다. 먼저 내부에서 공개했다가 준비되면 공개로 바꾸면 됩니다. 설치 방법은 둘 다 같습니다.
- **버전.** 공개된 버전은 절대 덮어쓰지 않습니다. 같은 핸들로 다시 공개하면 같은 항목에 버전이 하나 추가되므로 링크는 계속 동작하고 이력도 한곳에 모입니다. 이미 있는 버전 문자열로 다시 공개하면 거부됩니다.

### 공개자가 제외하는 값

MCP 서버에서는 `env` 값, 헤더 값, URL이 빈 값으로 바뀌고 매니페스트에 **설치 시 입력해야 하는 값**으로 표시됩니다. 항목을 설치하는 사람이 자신의 값을 입력합니다. 어떤 값이 정말 자격 증명이 아니라면 — 예를 들어 공개된 엔드포인트라면 — 작성된 그대로 공개하도록 표시할 수 있습니다.

서버의 `command`나 `args`, 또는 에이전트의 사용자 지정 인자에 자격 증명이 직접 적혀 있으면 값이 제외되는 대신 **공개가 실패합니다**. 프로세스 실행 명령을 말없이 고쳐 쓰는 것은 거부하는 것보다 나쁩니다. 그 값을 서버의 환경 변수로 옮긴 뒤 다시 공개하세요.

## 설치하기

항목을 열면 설치했을 때 무엇이 만들어지는지 볼 수 있습니다. 에이전트 템플릿이라면 함께 제공되는 스킬과 필요한 MCP 서버가 표시됩니다. 확인한 뒤 **설치**를 선택하세요.

양식에서는 항목이 알 수 없는 것만 묻습니다.

- **이 워크스페이스에서 사용할 이름.** 비워 두면 공개된 이름을 그대로 사용합니다.
- **런타임**(에이전트 템플릿의 경우). 템플릿은 머신을 지정하지 않으므로 내 워크스페이스에서 하나를 고릅니다. 템플릿이 다른 제공자 기준으로 작성되었더라도, 해당 런타임이 지원하지 않는 설정은 설치를 막는 대신 설정되지 않은 채로 남습니다.
- **공개자가 제외한 값**(항목에 있는 경우).

이름이 이미 사용 중이면 스킬 가져오기와 같은 선택지가 주어집니다. 다른 이름으로 설치하거나, 기존 항목을 대체하는 것입니다. 대체는 대체 대상 스킬을 처음 만든 사람만 할 수 있습니다.

## 설치는 사본이지 구독이 아닙니다

설치한 스킬이나 에이전트는 이후로 원래 항목을 따라가지 않습니다. 내 사본은 안전하게 수정할 수 있고, 항목에 새 버전이 나와도 누군가 설치하기 전까지는 아무것도 바뀌지 않습니다.

마켓플레이스는 어떤 버전을 받았는지 기억하므로, 더 새로운 버전이 공개되면 이미 가지고 있는 항목에 **vX로 업데이트**가 표시됩니다. 업데이트를 받는 것은 그 버전을 의도적으로 설치하는 일입니다.

<Callout>
설치된 스킬은 스킬 페이지에서 다시 받을 수 없습니다. "소스에서 업데이트"는 어떤 URL이 오늘 제공하는 내용을 다시 내려받는 것이고, 마켓플레이스의 업데이트는 내가 고른 버전을 설치하는 것입니다. 항목 페이지를 사용하세요.
</Callout>

## 항목 내리기

공개한 워크스페이스는 항목을 **지원 중단**으로 표시할 수 있습니다. 그러면 목록에서는 보이지 않지만 이미 그 항목에 의존하는 사람은 계속 설치할 수 있습니다. 또는 **내리기**를 하면 새로운 설치가 완전히 중단됩니다.

둘 다 이미 설치한 워크스페이스에는 영향을 주지 않습니다. 그 사본은 그들의 것입니다.

## 온톨로지

마켓플레이스의 네 번째 탭에는 온톨로지가 표시됩니다. 이것은 항목이 아닙니다. Capability Hub가 제공하며 워크스페이스로 복사되지 않고 에이전트에 연결됩니다. 이 탭이 있는 이유는 기능을 한곳에서 찾을 수 있게 하기 위해서이며, 연결 관리는 [온톨로지](/skills) 페이지에서 합니다.

## CLI 사용

```bash
enact marketplace list --kind skill --output json
enact marketplace get <listing-id> --output json
enact marketplace install <listing-id> --output json

# 에이전트 템플릿에는 런타임과 제외된 값이 필요합니다.
enact marketplace install <listing-id> \
  --runtime-id <runtime-id> \
  --secret env.GITHUB_TOKEN=... \
  --output json
```

공개 명령은 없습니다. 공개는 무엇이 워크스페이스를 벗어나는지에 대한 관리자의 결정이며, API는 에이전트 호출자의 공개 요청을 거부합니다.

## 권한

| 동작 | 대상 |
|---|---|
| 항목 둘러보기와 열기 | 모든 워크스페이스 멤버 |
| 스킬 또는 에이전트 템플릿 설치 | 모든 워크스페이스 멤버 |
| MCP 서버 설치 | 워크스페이스 owner 또는 admin |
| 항목 공개, 수정, 지원 중단, 내리기 | 공개한 워크스페이스의 owner 또는 admin |

에이전트는 둘러보고 설치할 수 있습니다. 공개는 할 수 없습니다.
