智能体会产出文件：报告、图表、导出的数据、截图。这些文件属于产出它们的那份工作，所以你就在那里找到它们。

**产物**是针对单个 issue 或单个对话会话的文件浏览器。从 issue 头部的文件夹按钮打开，地址是 `/{slug}/issues/{id}/artifacts`；对话会话头部有同样的按钮，地址是 `/{slug}/chat/{id}/artifacts`。

## 一个 issue 的产物包含什么

三个来源汇入同一个列表。

| 来源 | 出现的位置 |
|---|---|
| **挂在 issue 上的文件** | 顶部分组，标为「本任务」。 |
| **在评论中附加的文件** | 同一个顶部分组 —— 评论属于它所在的 issue。 |
| **子 issue 产出的文件** | 每个子 issue 一个文件夹，用它的 issue 编号和标题标注。 |

子 issue 只收一层。子 issue 是委派出去的工作的落点，否则一个由子任务完成产出的父任务看起来会是空的。孙级 issue 的文件留在拥有它们的那个子 issue 里。

对话会话没有可委派的下级，所以它的列表是平铺的。

## 版本

智能体执行从不覆盖文件。重跑一次会上传新文件，旧文件原样保留。

当两个文件的**产出 issue 相同且文件名相同**时，它们才是同一个产物的两个版本。行上显示的、直接下载得到的是最新的那个；更早的版本仍可在详情面板中取用。父 issue 和它的子 issue 各自产出了 `report.pdf`，那是两个产物，而不是一个文件的两个版本 —— 是 issue 让这个文件名有了意义。在一个对话会话内部，仅凭文件名就能确定一个文件。

## 查找、打开与删除文件

搜索按文件名过滤列表，对子 issue 文件夹还会按 issue 过滤。仍有匹配项的文件夹会自动展开。缩小搜索范围不会改变详情面板正在描述的是哪个文件。

在详情面板中，你可以预览 Enact 能在浏览器里渲染的文件、下载任意版本、跳转到文件所属的子 issue，以及删除某个版本。

<Callout type="warn">
删除会对所有人移除该版本，且无法撤销。如果该文件被内嵌在描述或评论中，那张图片或那个链接会失效。上传者和工作区管理员可以删除，其他成员不能。
</Callout>

<Callout type="info">
超大列表有上限。达到上限时浏览器会说明并给出总数。issue 自身的文件排在子 issue 的前面，所以被截断时先丢掉的是委派出去的那部分。
</Callout>
