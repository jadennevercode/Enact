智能体会产出文件：一份报告、一张图、一份导出的数据、一张截图。这些文件落在触发本次执行的 issue 或对话里 —— 在当下阅读它们是合适的，一周后再找就不合适了。

**产物**是同一批文件在工作区层面的视图。从侧边栏打开，地址是 `/{slug}/artifacts`。

## 浏览器的结构

左侧是目录树，右侧是所选内容的详情。

| 层级 | 含义 |
|---|---|
| **文件夹** | 文件来自的 issue，显示为该 issue 的编号和标题。 |
| **行** | 一个产物 —— 一个文件名，以及它的全部版本。 |
| **详情** | 所选产物的每个版本，最新的在前，可以单独下载。 |

在[对话](/chat)中产出的文件同样列在这里。它们过去没有可以归集的地方，因此从来不会出现在任何浏览视图中。

## 版本

智能体执行不会覆盖文件。重新执行一次会上传一个新文件，旧文件原样保留。

两个文件在**属于同一条 issue 且文件名相同**时合并为同一个产物的两个版本。行上显示的、直接下载得到的是最新的那个，更早的版本仍可在详情面板中取到。两条不同的 issue 各自产出的 `report.pdf` 是两个产物，而不是一个文件的两个版本 —— 是 issue 让文件名有了含义。

## 查找和打开文件

搜索按文件名和文件夹过滤目录树，仍有匹配的文件夹会自动展开。缩小搜索范围不会改变详情面板正在描述的文件。

在详情面板中，可以预览 Enact 能在浏览器里渲染的文件、下载任意版本，以及跳转到文件来自的 issue。

<Callout type="info">
超大列表会被截断。达到上限时浏览器会说明这一点并给出总数，因此不会把一棵不完整的树误认为整个工作区。
</Callout>
